# UI examples

Desktop captures from the local app. Files 01–03 use a 1920×1080 viewport. Files 04–08 use a 1440-wide viewport (signed-in Chrome session) and are stitched from scrolled viewport shots. Full-page shots are the whole scroll height. The launch modal is an overlay, so those two files are one screen.

| File | What it is |
|---|---|
| `01-homepage-desktop-20261020-1534.png` | Homepage, full page. 1909×7338. |
| `02-launch-mind-desktop-20261020-1536.png` | Launch a Mind, Custom. 1920×1080. |
| `03-launch-mind-templates-desktop-20261020-1536.png` | Launch a Mind, Templates. 1920×1080. |
| `04-profile-home-desktop-20261021-1514.png` | Profile Home (`/profile`), full page. 1429×1731. |
| `05-profile-my-minds-desktop-20261021-1514.png` | My Minds (`/profile?tab=minds`), grid view, page 1. Full page. 1429×1531. |
| `06-profile-mind-detail-desktop-20261021-1514.png` | Mind detail (`/profile/minds/<id>`), Street.Fashion. Full page. 1429×2654. |
| `07-profile-referral-desktop-20261021-1514.png` | Referral (`/profile?tab=referral`), Refer a friend tab. Full page. 1429×784. |
| `08-profile-connectors-desktop-20261021-1514.png` | My Connectors (`/profile?tab=connections`). Fits one screen. 1440×777. |
