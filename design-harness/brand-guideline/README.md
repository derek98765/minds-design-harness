# Minds brand guidelines

This folder contains two versions of the brand guideline. Both cover the same core brand system (logo, mascot, color, typography), but differ in depth and file size.

## Files

| File | Pages | Size | Contents |
|---|---|---|---|
| `brand-guideline-full.pdf` | 34 | ~47 MB | Complete brand guideline — logo usage rules, mascot poses/variations, full color system, typography specs, and additional sections beyond the summary (likely spacing, imagery, do's/don'ts, applications, etc.) |
| `brand-guideline-lite.pdf` | 1 | ~1.2 MB | Single-page condensed summary — logo, mascot, color palette, and typography basics only |

## When to read which

**Read `brand-guideline-lite.pdf` when you need:**
- A quick reference for core brand basics (logo, colors, fonts)
- Fast lookup of hex codes or font names
- A lightweight file to share or skim (small size, single page)
- Onboarding someone who just needs the essentials

**Read `brand-guideline-full.pdf` when you need:**
- Complete/official brand rules before production work (marketing materials, product UI, merch, etc.)
- Details not in the lite version — usage restrictions, edge cases, more mascot poses, layout/spacing rules, or application examples
- The authoritative source if the lite version and full version ever conflict

## Reading tips (for Claude or humans)

- Both PDFs are primarily visual/layout-driven — colors, logos, and type samples are shown as images, so read them as PDFs directly rather than converting to plain text (text extraction alone will miss swatches and layout).
- Always pull hex codes and font names from the stated text in the PDF, not by visually estimating from swatches.
- The full version is large (34 pages); if only checking one thing (e.g. "what's the primary blue?"), the lite version is faster and usually sufficient.

## Quick brand reference

- **Colors:** Warm canvas `#ECE7E0` (the default page surface), Brand Orange `#FD8D1D`
  (action only), Brand Blue `#394F95` (structure). Tints: `#FFAC68`, `#E09557`,
  `#9CA7CA`, `#CCCCCC`, `#888888`.
- **Typography:** Manrope (Google Font) — extrabold 800 for headings, regular 400 for
  body; Noto Sans TC/SC for Chinese.
- **Logo/Mascot:** "Minds" wordmark with the dot-eyed circular mascot (Abby), in blue
  and white variants.
