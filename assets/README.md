# Assets

A curated subset of the Minds asset library — the pieces a campaign page actually needs.
The full library lives with the design team; this is what's worth having to hand.

## Logo — `logo/`

| File | Use |
|---|---|
| `minds-blue.svg` | **Default.** Warm canvas, white, any light surface. |
| `minds-white.svg` | Indigo canvas, photography, any dark surface. |
| `minds-blue.png` · `minds-white.png` | Only where SVG isn't supported (email, some social). |

Prefer SVG on the web. Minimum 120px wide — below that use the icon mark alone.
Rules and the eight don'ts: [../spec/brand-logo.md](../spec/brand-logo.md).

## Abby the mascot — `mascot/`

| File | Why this one |
|---|---|
| `abby-arms-crossed.png` | Front-facing and confident — the default hero pose. |
| `abby-waving.png` | Welcome screens, confirmations, thank-you states. |
| `abby-pointing.png` | Sits beside a headline and points into it. |
| `abby-gesturing.png` | Open-handed, mid-explanation — pairs with a feature. |
| `abby-celebrating.png` | Success states and completed actions. |
| `abby-leaning.png` | Mid-motion; use where the layout needs energy. |
| `abby-reference-turnaround.png` | **Not for placement.** The four-view sheet you attach when generating new Abby imagery. |

Match the gesture to what the copy says. One Abby per section.
Rules: [../spec/brand-mascot.md](../spec/brand-mascot.md).

## Hand stickers — `stickers/`

| File | Why this one |
|---|---|
| `hand-pointing.png` | Points at a headline or a single stat. |
| `hand-ok.png` | Confirmation, "you're set", a completed step. |
| `hand-open.png` | Neutral and welcoming — the safe default. |
| `hand-thumbs-up-stars.png` | Testimonials and ratings. |
| `hand-handshake-checklist.png` | Sign-ups, registrations, agreements. |

A separate accent system from Abby — small, punctuating one point. One or two per
page. Don't mix a sticker into a scene that already has a full Abby.

## Photography — `photos/`

| File | Audience | Scene |
|---|---|---|
| `everyday-hero-desk.png` | Everyday user | Home desk, warm orange wall, Abby on the laptop |
| `everyday-kitchen-cooking.png` | Everyday user | Kitchen, cooking, two Abbys in the scene |
| `everyday-family.png` | Everyday user | Family setting |
| `builder-hero.png` | Builder | Workspace, building something |

Pick the set matching the page's reader — a consumer landing page shouldn't lead with
a builder image. Direction and the locked AI-generation prompts:
[../spec/brand-imagery.md](../spec/brand-imagery.md).

---

**Note on file size.** These are full-resolution source files. Compress and resize
before shipping them on a real page — a 5MB hero image is a slow page, and slow pages
lose the reader before the design ever matters.
